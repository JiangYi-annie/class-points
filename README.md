# 班级积分排行榜（静态版）

给班级用的作业 + 课堂表现积分排行榜网页。纯静态，无后端、无数据库，只靠 **三个文件 + GitHub 接口** 跑起来：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构与样式 |
| `app.js` | 榜单、查询、教师后台、GitHub 读写逻辑 |
| `data.json` | 所有数据（学号、作业记录、课堂加分、荣誉墙评选） |

- 默认打开就是**作业提交榜前五名**，上课投屏用。
- **课堂点名**：随机滚动学号、一轮不重复，答对 +2 分自动计入总榜。
- **荣誉墙**：作业之星、笔记之星每两周评选 3 人，点击学号看扫描件。
- 学生输入学号，就能看到自己的**总排名、积分、连击、提交情况**。
- 教师用手机/电脑在「教师」里**导入作业、随手加分、录入荣誉墙**，数据写回 `data.json`，网页自动更新。

只记录学号（默认 `01`–`43`），**不记录姓名、班级或学校信息**。

---

## 一、5 分钟部署到 GitHub Pages

1. 在 GitHub 新建一个 **Public** 仓库，比如 `class-points`。
   （免费账号的 Pages 只支持公开仓库，而且家长学生要能直接打开链接，所以必须 Public。）
2. 把 `index.html`、`app.js`、`data.json` 三个文件上传到仓库**根目录**。
3. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支选 `main`、目录选 `/ (root)` → **Save**。
4. 等 1–2 分钟，打开 `https://你的用户名.github.io/class-points/`。
5. 打开页面右上角 **教师**，完成一次 GitHub 连接（见下文）。

> 首次部署后页面显示「榜单等着第一次作业」，这是正常的，导入第一次作业就会点亮。

## 二、第一次连接 GitHub（教师）

网页是静态的，导入和加分要把改动写回仓库里的 `data.json`，所以需要一次连接。**Token 只保存在你这台设备的浏览器里，不会写进网页或 data.json。**

在「教师 → 连接 GitHub」里填：

- **仓库**：`你的用户名/class-points`（在 GitHub Pages 上会自动带出）
- **分支**：`main`
- **数据文件路径**：`data.json`
- **Token**：下面生成的 `github_pat_…`

### 生成 Token（细粒度，只给这一个仓库）

1. GitHub 右上角头像 → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**。
2. Repository access 选 **Only select repositories**，只勾选 `class-points` 这一个仓库。
3. Permissions → **Repository permissions** → **Contents** 设为 **Read and write**（Metadata 保持只读即可）。
4. 生成后复制 `github_pat_…`，粘贴到网页里，点「连接并测试」。

> 安全建议：**不要用**带 `repo` 全权限的经典 Token；用细粒度 Token 只授权这一个仓库。Token 一旦泄露，立刻到 GitHub 里 Revoke（撤销）。

## 三、日常怎么用

### 上课前（投屏）
点右上角 **⛶ 全屏**，把浏览器投到大屏。页面每 20 秒自动刷新一次。

### 上课中（课堂点名）
顶部导航 **点名**：
- 点 **点名** 开始随机滚动学号，点 **确定** 锁定。
- 锁定的学号会停在窗口里，点 **回答正确 +2** 记 2 分（自动计入总榜），点 **回答错误 0** 不加分。
- **一轮内每人只出现一次**，抽完自动进入下一轮；「重置本轮」可让已抽过的人重新进入随机池。
- 点名的轮次状态存在教师这台设备的浏览器里，刷新/断网不丢本轮进度。
- 说明：答对的 +2 直接写进 `data.json` 的课堂记录、和课堂加分/作业一起算总榜（没有单独的点名 json），所以分数即时生效，也不会漏。

### 上课中（课堂加分）
手机上打开网页 → **教师** → **课堂加分**：
- 点一下某个学号就 +1 分（可切换 +1 / +2 / +3，可写备注）。
- 点错就到「课堂加减分记录」里点撤销按钮，或点「撤销上一条」。
- 加分先记在本机，几秒后自动合并成一次提交写回 GitHub。

### 批改完作业（导入）
**教师 → 导入作业**：
- 日期默认今天，作业名称留空会自动命名「第 N 次作业」。
- 登记方式推荐「默认全员已交，只登记未交」——批改完只需要把**没交的学号**填进去（空格/逗号/换行分隔）。
- 确认人数无误后点「确认导入」，系统自动给每个完成者加分、更新连击和排名。
- 同一天同一名称再导入一次会提示**覆盖**，方便改错。

### 每两周（荣誉墙评选）
主页下方的「作业之星 / 笔记之星」两个框展示最近一期。教师 → **荣誉墙评选**：
1. 选类型（作业之星 / 笔记之星）、填日期、填 3 个学号，保存。
2. 把 3 份扫描件按下面的路径上传到 GitHub 仓库：

```
stars/homework/20261108/01.jpg     ← 作业之星，日期/学号
stars/notes/20261108/01.jpg        ← 笔记之星
```

支持 `.jpg / .png / .webp`。学生/家长在主页点两个框 → 点某一期 → 点学号，就能看到对应的扫描件。

## 四、积分与排名规则

- **总分 = 作业积分 + 课堂积分**。
- **作业积分**：每次作业按「每次得分」加分，默认 +2（可在设置里改，改只影响之后导入的作业）。
- **课堂积分**：主动回答问题、上台演示等，默认 +1。
- **连击（连续提交）**：最近连续完成的作业次数；某次没交就归零。「最佳连击」是历史最好成绩。
- **提交率**：完成次数 ÷ 总作业次数。

### 排名并列时依次比较
- 作业榜：作业积分 → 课堂积分 → 连击 → 学号。
- 总榜：总分 → 作业积分 → 课堂积分 → 学号。

## 五、学生怎么查自己

打开网页 → **我的成绩** → 输入学号（`7` 也会自动识别成 `07`）。能看到：

- 总榜排名、作业榜排名、总积分；
- 作业 / 课堂积分的占比；
- 连击、最佳连击、提交率、最近几次作业的 ✓/✗；
- 一句鼓励：距上一名还差几分、再完成一次作业能否进前五。

> 只有学号，没有姓名。任何人拿到链接都能看到榜单上的学号和分数，这符合「班级积分榜」的用途；如果学号也算敏感信息，请改用匿名编号。

## 六、数据、备份与撤销

- 所有数据都在 `data.json` 里，可用「教师 → 备份与重置 → 导出 JSON」备份。
- 「从 JSON 恢复」会整体覆盖当前数据（操作前会再确认）。
- 「清空本学期记录」删除全部作业和课堂记录，保留学生名单。
- 删除某次作业：作业记录右侧的删除按钮，会重新计算所有人的积分和连击。
- 换学号/名单：教师 → 设置 → 学生名单。**修改学号会被当成新学生，历史记录不会自动迁移**，所以请在正式记录数据前先把名单改成你们班的真实学号。

## 七、常见问题

**改完数据，投屏页没变？**
GitHub Pages 重新部署通常要 30–60 秒。教师自己那台设备直接读 GitHub 接口，是即时的；学生设备走 Pages，最多等一分钟，投屏页每 20 秒自动刷一次。

**显示「Token 无效 / 没有权限」？**
检查 Token 是否还在、有没有过期，仓库名/分支/路径是否写对，Contents 权限是否为 Read and write。

**提示「找不到 data.json」？**
`data.json` 要和 `index.html`、`app.js` 在同一个目录（仓库根目录）。

**打开网页白屏 / 数据加载失败？**
确认是通过网址访问（GitHub Pages 或本地 `http://localhost`），**不要直接双击 `index.html`**——浏览器会拦截读取本地 JSON。

**本地想先试试？**
在 `class-points` 目录里运行 `python -m http.server 8000`，再打开 `http://localhost:8000`。

## 八、隐私与安全

- 页面带 `noindex`，搜索引擎不收录；但 `data.json` 本身是公开文件，任何拿到仓库链接的人都能读到（只有学号，没有姓名）。
- Token 只存在教师设备的 `localStorage`，页面不加载任何第三方脚本（有 CSP 限制），也不会把 Token 发给 GitHub 以外的服务器。
- 不要在学生共用的电脑上「记住 Token」；离开时点「断开」可清除。
- 不要在直播/录屏时打开教师后台，避免把 Token 或未交名单露出去。
